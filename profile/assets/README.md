# Ducoro brand assets

| Asset | Usage |
| --- | --- |
| `ducoro.svg` / `ducoro.png` | Standalone presentation, including the organization README. Includes a rounded black backplate and transparent corners. |
| `ducoro-github-avatar.svg` / `ducoro-github-avatar.png` | GitHub organization avatar. Uses a full-bleed opaque black square; GitHub supplies the display corner radius. |

Both PNGs are 1024 × 1024 pixels. The white mark uses the same geometry, scale, and placement in both variants. Select the backplate for the destination: platforms that mask avatars receive the full-bleed square.
