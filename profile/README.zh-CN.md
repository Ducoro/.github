# Ducoro

**把你的 Bot 收进 Ducoro。**

让你的事情持续运转，把注意力还给你。

[官网](https://ducoro.ai)

[English](https://github.com/Ducoro/.github/blob/main/profile/README.md)

Ducoro 让一件事交出去一次，以后自己转；该你拍板时才来找你。围绕你托付的事情，Lead 组织 Bot 协作、推进执行，把结果和需要你判断的决定带回来。

- **交代目标。** 说清要达成什么，以及执行的边界。
- **持续运转。** 让 Bot 承接日常执行与协调。
- **保留拍板权。** 查看结果，在需要你判断的地方做决定。

## 开源项目

[**官方插件**](https://github.com/Ducoro/plugins)扩展 Bot 的能力。插件目录通过 GitHub 独立维护和更新，新增插件无需等待 Ducoro 应用发版。

你可以浏览插件、阅读使用说明，并按照仓库的贡献指南参与改进。
